# Chesstify

Chesstify is a modern web application designed for chess enthusiasts, offering advanced tracking of chess moves and detailed performance statistics. The application acts as a central hub for players to analyze their gameplay history and store complex board states.

## Problem Statement

Managing chess games accurately requires keeping track of PGN (Portable Game Notation) formats, parsing them reliably, and presenting the historical data in a way that is intuitive to users. Storing high-throughput move data efficiently can be challenging.

## Solution

I built the backend using **Node.js** and **Express**, paired with a **PostgreSQL** database. Using raw SQL combined with optimized indexing allowed for sub-second retrieval of a player's historical moves. The frontend is built with **React** to dynamically render chessboards using the `chess.js` library for move validation.

### Key Features
- **Real-time move validation** using `chess.js`
- **Game History Tracking** stored securely in PostgreSQL
- **Responsive Design** for chess playing on mobile and desktop
- **User Authentication** to save game progress

## Technical Implementation

- **Database Design**: Structured relational tables to map `Users(1) -> Games(N) -> Moves(N)`. 
- **API Architecture**: REST APIs deployed on Express with strict validation middlewares.
- **Frontend State**: Complex state management for handling ongoing matches, captured pieces, and move-time tracking.

> [!NOTE]
> This project significantly improved my understanding of relational database schema design and optimized querying for complex relational data.
